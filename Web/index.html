Setup Instructions / General Info

Step-by-step installation:

  • Find a wall with a free space of at least 2 m wide and 1.5 m tall.
  • Start from the bottom string, placing the letters and lights at the height you want them.
  • Plug in the bottom string first, before connecting the middle string.
  • On your phone, check the Wi-Fi networks — you should see BYERSWALL LA R-Z.
  • Join this network. A setup page will appear asking you to select a Wi-Fi network and enter a password.
  • Enter the office’s public Wi-Fi credentials (the same one your personal devices use).
  • If accepted, the lights will flash to indicate a successful connection. This only needs to be done once per string (unless Wi-Fi changes).
  • Test each light by moving your hand near the black sensor base — they brighten as you get closer (0–10 cm).
  • Rejoice! 🎉
  • Proceed with the middle and top strings, repeating these steps.
  • The middle string connects to the bottom for power; the top connects to the middle.

Note: Sometimes you’ll need to try multiple times for the Wi-Fi credentials to be accepted.
If it doesn’t seem to connect, unplug the string, wait 5 seconds, and plug it back in.
The Wi-Fi network will reappear so you can try again. (At the office, one string took over five attempts — sorry it’s a little finicky!)
